# Collie 视觉语言规范(design-language)

## 1. 品牌内核

- 名字来自 Border Collie 牧羊犬——「放牧一群 agent」。品牌角色是**牧羊犬**(中控 / lead agent 的人格化),不是宠物狗。
- 调性:工程感、克制、可信;幽默只出现在意象,不出现在质感。
- 三个品牌母题(motif),后续所有图形从这里取:
  1. **双色脸(split-face)**:边牧标志性的不对称花色 → 图形手法 = 垂直二分割,墨/纸强对比。寓意「中控看两边:人/agent、任务/工作区」。
  2. **光标(cursor)**:终端方块光标 = CLI 血统,用作眼睛、犬牌、提示点的造型语言。
  3. **状态四色**:agent 语义状态(working / blocked / done / idle)是产品的核心信息,颜色直接复用到品牌图形。

## 2. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨 ink | `#12141A` | 主背景 / 深色面 |
| 纸 paper | `#F2EFE6` | 主前景,偏暖,避免纯白刺眼 |
| 岩 slate | `#33404E` | 容器底色,明暗之间的过渡色 |
| 哨橙 whistle | `#ED8B33` | 唯一品牌强调色(牧羊哨 / 犬牌),只用于关键动作与记忆点,不大面积铺 |
| working | `#3FB96B` | 状态语义,不做装饰 |
| blocked | `#E5B23B` | 状态语义 |
| done | `#5B8DEF` | 状态语义 |
| idle | `#38414D` | 状态语义,低饱和 |

对比度:纸 on 墨 ≈ 15:1,哨橙 on 墨 ≈ 7:1,均过 WCAG AA;状态色在墨底上 ≥ 4.5:1(正文级使用前再逐一校)。

## 3. 字体

- 代码 / 数据:JetBrains Mono(中文等宽回退 Sarasa Mono / 系统等宽)
- UI 正文:Inter;中文 PingFang SC / Noto Sans SC
- 字重克制:正文 400/500,标题 600,不用 700+

## 4. 造型

- 容器:圆角矩形(radius ≈ 边长 22–23%,对齐 Apple squircle 观感),头像 / 图标出血铺满。
- 图形语言:平面几何、圆角接头、无渐变无投影;「一个意象 + 一个强调色」,每幅图形只讲一件事。
- 网格:512 基准画板,8px 网格;关键元素 ≥ 40px,保证 96px 缩略可读。

## 5. 出稿纪律

- 每个候选附:意象说明、取舍、96px 小尺寸验证。
- 源文件(SVG)沉淀本目录;效果图以 issue 附件交付。
- 品牌定调与对外物料最终采用归 owner。
