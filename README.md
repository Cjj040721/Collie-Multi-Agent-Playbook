## 1. Overview

Collie is **not a finished software product**. It is a public playbook for learning how multiple projects and AI agents can work together without losing ownership, evidence, or momentum.

The repository serves two purposes:

1. **An operating manual for future sessions and collaborators:** project roles, work cycles, ledger rules, tool boundaries, and weekly review mechanisms.
2. **A product-discovery archive for Collie:** why a central control agent might matter, how review effort could be tiered, and which open questions remain before choosing an architecture.

The current product decision is **workflow first, app later**. Existing tools such as herdr, Orca, and Multica are used to test the methodology; product requirements should emerge from real use rather than speculation.

## 2. 中文文档地图

这个目录不是代码项目,是**工作方法论的沉淀地**和 **Collie(多 agent 协作工具)的需求素材库**。

核心决策(2026-07-30):**工作模式先行,Collie app 缓建**——先用现有工具(herdr / Orca / Multica)+ 文档纪律跑通多项目协作,需求素材从真实使用中长出来。

### 这是什么

- **给未来的自己和新 session 的 agent 看**:跨项目通用的协作流程、台账规范、工具分层、每周复盘机制。
- **Collie 的基石文档**:为什么做、差异化洞察(中控 agent 一等公民 + 分级复核成本结构)、开放问题。
